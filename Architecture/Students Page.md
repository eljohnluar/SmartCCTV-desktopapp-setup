# Students Page

> `frontend/src/pages/Students.jsx`

The student management interface for enrollment, updates, and verification workflows.

## Responsibilities

- Creates and edits enrolled student records
- Handles face enrollment and profile data capture
- Displays student lists by section and status
- Feeds updates into the backend via [[REST API]] and [[Database]]
