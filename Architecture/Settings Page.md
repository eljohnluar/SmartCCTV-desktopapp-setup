# Settings Page

> `frontend/src/pages/Settings.jsx`

Configuration dashboard for the operating parameters that govern security and attendance behavior.

## Responsibilities

- Displays system settings for cameras, detection thresholds, and policies
- Allows updates to attendance and compliance rule configuration
- Persists user-facing configuration through the backend API
- Reflects system state collected from [[Config]] and [[Database]]
