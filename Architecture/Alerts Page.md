# Alerts Page

> `frontend/src/pages/Alerts.jsx`

Review and respond to security alerts raised by the monitoring pipeline.

## Responsibilities

- Lists active and historical alerts
- Displays alert metadata, timestamps, and severity information
- Supports review actions for flagged incidents
- Receives live updates from [[WebSocket Manager]]
