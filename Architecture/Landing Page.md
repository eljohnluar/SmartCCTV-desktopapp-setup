# Landing Page

> `frontend/src/pages/Landing.jsx`

The public entry point for the SmartCCTV application before a teacher logs in.

## Purpose

- Presents login and registration views
- Collects username, password, and teacher clearance code
- Routes users to the authenticated dashboard after successful authentication
